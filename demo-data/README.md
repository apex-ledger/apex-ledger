# North Ledger DEMO / TEST companies

These datasets are intentionally non-client demo data and are retained for user inspection and regression testing.

Planned final demo companies:
1. CRA/GIFI Validation Company — financial-statement/GIFI benchmark.
2. Ontario Service Company — invoices, expenses, HST, partial receipts/payments.
3. Ontario Retail & Inventory Company — PO, partial receipt, GRNI, supplier bill match, inventory, COGS, sales, credits and banking.

All demo companies must be visibly labelled DEMO / TEST in the company selector and dashboard. They must use separate company databases and must never be merged with live-company data.
